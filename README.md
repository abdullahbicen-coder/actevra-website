# Actevra Engineering Website

Static corporate website for **Actevra Engineering**.

## Structure

- `index.html` — main landing page
- `styles.css` — site styling
- `script.js` — navigation, reveal animations and email copy helpers
- `assets/` — local SVG industrial illustrations
- `references/` — anonymized project reference pages

The project contains no customer names, project codes or location-identifying information.

Designed for static hosting such as GitHub Pages.
