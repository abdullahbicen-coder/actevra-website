# Actevra Engineering Website

Static corporate website for **Actevra Engineering**.

## Structure

- `index.html` — main landing page
- `styles.css` — responsive industrial design
- `script.js` — navigation, reveal animations and email copy helpers
- `references/` — anonymized project reference pages

The public portfolio intentionally contains no customer names, project codes or location-identifying information.

Designed for static hosting with GitHub Pages.
